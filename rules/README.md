# FanYu Rules

这是番遇的视频源规则仓库。应用先读取 `index.json`，用户安装时再下载对应的单条规则文件。

## 目录约定

- `index.json` 只保存商店展示、版本比较和下载地址所需的轻量信息。
- `{id}.json` 保存一条可安装的完整规则。
- `id` 一经发布应保持稳定，名称和站点域名可以随版本更新。
- 暂时失效的规则使用 `unstable`，确认不可用后使用 `deprecated`，不要立即删除文件。

## 发布检查

1. 提高规则文件和索引中的 `version`。
2. 确保 `downloadUrl` 能通过 HTTPS 下载。
3. 确保规则中的 `id` 与索引一致。
4. 验证搜索、线路和集数选择器至少能完成一次完整解析。
5. 同步更新应用内 `assets/rules`，作为仓库不可达时的备用目录。

当前规则格式为 `schemaVersion: 1`，对应番遇现有 CSS 解析能力。后续 XPath/API 规则会使用更高的 schema 版本并保留向后兼容。
